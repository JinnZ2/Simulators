# GAP_INDEX.md

Every open question in this repository, one row each. Generated by
`tools/gap_index.py`; do not edit by hand — regenerate.

A folder appears here only if it carries an open-questions document,
either as `OPEN_QUESTIONS.md` or as the section of that name inside
its `OPEN_RESEARCH.md`. Folders without one are skipped in silence:
most folders here have never been rendered, which is a fact about
the rendering pass and not about the folder.

Every cell is a field the document declared. Where a document did
not declare one the cell reads `unrecorded`, which is a different
statement from a gap having no discipline or needing no data.
Nothing here is inferred from wording.
