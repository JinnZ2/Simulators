Delivered 2026-08-25. Verbatim. Nothing in this file is edited.

Scan two, companion absence — for every flagged cell, check the surrounding neighborhood for a unit string, a date, a sample size, or any variance-like sibling. Report what's missing rather than what's present.

Scan three, header collision — collect column and row labels across all sheets, group by normalized string, and flag any label whose cells differ in precedent depth or in whether they're constants versus derived. Same name, different construction.

Ranking: dependent count times downstream depth, so the sites that propagate furthest sort to the top.

Output as a plain table, no interpretation, no severity language. Two constraints worth stating in the spec itself: stdlib plus one spreadsheet reader, and the tool never labels a site as an error — it reports structure and the reading stays with the operator.
