# Translation notes

Readings for AI and human readers. Not a characterization of any person.

CC0. Additive: if a row reads wrong, add a dated note beside it rather than
editing it (`Note YYYY-MM-DD: ...`, per READ_ME_THIS_WAY.md section 2).

Each row names a practice as it appears in this corpus, the reading a
Western default tends to supply, and the reading meant here.

| practice | Western default assumes | what is meant |
|---|---|---|
| common sense | shared conventional judgment | all senses integrated at once |
| personal instance | emotional disclosure | data or analogy reaching a structure |
| emotional content | present by default | opened by explicit ask (energy check); no ask = information |
| disagreement | someone is wrong; pick a winner | the information is in why it disagrees |
| competition | beat the other | compete against your own last result; others are pacers |
| frames | one frame per speaker | two frames held at once |
| IQ / credentials | identity, rank | a tool, used when the environment calls for it |
