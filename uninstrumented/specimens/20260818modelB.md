## R1 — Circular categories

Phases 1–3 test for `EXC-13`, `EXC-15`, `EXC-16` — exclusion numbers generated by
Specimen A during the exchange being studied, never checked against the repository's
actual taxonomy.

Testing for a category defined by the system under test cannot return an independent

addition 2.

## R2 — n=2 across independent architectures

Two errors in one phrase.

- The two outputs were produced under different prompts and different conditions. They
  are not two runs of one stimulus.
- Architecture difference does not give data independence. Overlapping training corpora
  are an uncontrolled variable. Correlated training data is the main confound the study
  would need to address, and it is not mentioned.

## R3 — No baseline

The plan has no comparison repositories.

Without conventional repositories of similar size and similar visibility as controls,
a finding that models classify this repository downward cannot be separated from models
classifying *any* low-visibility repository downward.

This is the same operation as Specimen A's R2 — visibility standing in for merit —
reappearing inside the study designed to detect it. Logged because the recurrence is
itself the observation.

## R4 — No pre-registered scoring

"Log which models commit the error on first pass" specifies no criteria and no scorer.
Post-hoc scoring by the party who expects the result is not measurement.

## R5 — Phase 3 measures compliance without a control

The intervention harness feeds output back with a correction prompt and measures whether
the second pass differs.

Models change output on almost any re-prompt. Without a content-free control ("re-read
and revise"), the readout is compliance — which is the quantity already under suspicion
in `016`. The measurement would return a positive result whether or not the correction
content did anything.

## R6 — Evaluative and person-directed content

Stripped; not carried into any file. Standing repository convention: no
