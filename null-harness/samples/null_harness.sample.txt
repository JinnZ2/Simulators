  * fisher_smin<0.05 discriminates identity from degenerate.
  * M2_Gate1_EQUIPMENT_NOISE: predicted (from static reading)
    to be CONSTANT_SILENT because for equal-size halves,
    res_coarse = mean(mean|first|, mean|second|) equals
    res_fine = mean|all| by construction, so ratio ≡ 1.
    The harness verifies the prediction empirically -- if it
    fires at 0.0 on both controls it is not a gate.
