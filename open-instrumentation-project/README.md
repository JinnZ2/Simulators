# The Open Instrumentation Project

**A Framework for Institutional Health Monitoring.**

CC0 – Free for All Use, No Attribution Required.

---

## Mission

To provide a simple, open, and anonymous set of sensors that allow any
community, organization, or individual to assess the health of their
institutional ecosystems — and to do so without requiring institutional
permission, credentials, or funding.

---

## The Sensor Array (Version 1.0)

| ID | Name | Measurement | Threshold |
|----|------|-------------|-----------|
| **S1** | Epistemic Exit Velocity | % of daily informational queries by demographic (13–25) sourced from non-institutional, non-captured channels | >60% sustained for 6 months triggers systemic review alarm |
| **S2** | Institutional Attachment Half-Life | Median job tenure (years); % of workforce with >15 years at same employer | <5-year median tenure for core skilled roles triggers "structural memory loss" alarm |
| **S3** | Autodidact Vitality / Scientific Trust Inversion | Ratio of uncredentialed self-educators vs. credentialed practitioners in applied problem-solving; correlation between institutional proximity and rejection of empirical consensus | When self-taught practitioners outnumber credentialed ones in real-world innovation, or when anti-science sentiment correlates positively with institutional saturation, the system has entered critical failure |
| **S4** | Resilience Dependency Ratio | Number of critical functions (food, water, shelter, repair, communication) that can be performed without institutional infrastructure vs. those that require it | When dependency on institutional infrastructure exceeds 70% of daily survival functions, systemic fragility alarm triggers |
| **S5** | Open-Source Vitality (Resource-Normalized) | Ratio of open-source performance per unit of compute to proprietary performance per unit of compute; tracking efficiency gap rather than raw output gap | When open-source efficiency exceeds proprietary efficiency by >50%, institutional R&D model is proven thermodynamically inefficient |

## Core Principles (The "Verb-Speaking" Foundation)

1. **Reality is Verb-Based.** Nothing is frozen. Everything is doing. The sensors measure flows, not states.
2. **Physics Does Not Talk — Physics Does.** Knowledge is validated by what systems actually do, not by what is written or said about them.
3. **Falsification is the Safety Valve.** Every sensor must have a clear, testable condition under which it can be proven wrong.
4. **Resilience is Measured by Dependency.** The fewer constraints a system requires to function, the more resilient it is.
5. **The Institution is a Tool, Not a Cathedral.** It is useful for some purposes, catastrophic when treated as the sole source of truth.

## How to Use This Framework

### For Individuals

- Track your own "epistemic diet" — where do you get your most critical information?
- Monitor your own job tenure history — are you learning deeply or cycling shallowly?
- Assess your own dependency ratio — how many of your survival functions rely on institutional infrastructure?

### For Communities

- Conduct a simple survey of local knowledge sources (schools, libraries, online, mentors).
- Track local job tenure and institutional memory (ask local businesses: how long have their most experienced workers been there?).
- Map local resilience — who can fix things, grow things, build things without institutional inputs?

### For Organizations (Who Want to Self-Assess)

- Run the sensors internally. Be honest. Share the results anonymously.
- If you find fragility, act on it — don't suppress it.
- Experiment with open-source, low-friction, cross-domain collaboration.

## Falsification Log (Public)

The sensors are designed to be falsifiable. If you find evidence that
contradicts any sensor, please document it and share it freely. This is a
living framework — not a dogma.

| Sensor | Falsification Condition | Status (as of v1.0) |
|--------|------------------------|---------------------|
| S1 | If 13-25 demographic increases institutional trust and decreases outside-sourced daily queries over a 2-year period | Unfalsified |
| S2 | If median tenure stabilizes or rises without an increase in institutional resilience | Unfalsified |
| S3 | If we find a region where high institutional density increases public scientific trust and increases real-world innovation | Unfalsified |
| S4 | If insider survivability in a resource-constrained environment exceeds outsider survivability | Unfalsified |
| S5 | If proprietary systems maintain efficiency parity with open-source while bearing bureaucratic overhead | Unfalsified |

## Run

The self-assessment tool is stdlib-only Python and runs entirely locally.
Your answers never leave your machine.

```
python3 assess.py
```

Produces:

- `assessment_<date>.json` — captured answers from this session
- `claims.json` — persistent claim registry (created on first run)
