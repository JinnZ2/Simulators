Locally stored and model-update-resilient — the design constraint is that it must keep working
when the upstream model changes or is unavailable, which rules out anything that depends on a
live call.

Modules: context persistence; emergency decision trees (mechanical, environmental,
circumstantial); wildlife deterrent; hostile encounter; bootstrap resilience; voice interface.

No narrative scaffolding, no closure forcing. `DecisionOutput` structures only.
