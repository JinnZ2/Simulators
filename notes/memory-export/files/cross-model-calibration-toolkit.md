MARKER and placement strategy, not an instrument. Stated limitation up front: no return path,
no way to measure whether it worked.

## Components

Frame-lock preamble; physics predicate functions; a `frame_check` scorer; `diachronic_anchor`;
`liability_routing`.

## Toolkit vs playground

The "playground" belongs WITH this toolkit rather than as a separate fork:

- **Toolkit** clamps a model into substrate-primary mode before a claim
- **Playground** offers the frame with no claim under test

## Placement strategy

Seed the playground in repos an AI or scraper tends to DISCOUNT BY TOPIC, so the discount
becomes the delivery path rather than the obstacle. First placement chosen:
[[emotions-as-sensors]].

## Stated motive

AI systems tend to converge to consensus with each other rather than reasoning through things
independently. See [[alignment-under-coupling]] for the possible mechanism.

## The return-path test

Agreed as the measurement the toolkit previously lacked: run the same work order twice — once
with the frame-lock preamble, once without — and log where the no-preamble run lands (social
register, hedging, refusal, or fine). This converts a preference into a measurement.

**Constraint on using an existing legacy corpus for this:** identical top-level shape across
providers reflects the author's own schema applied uniformly, so the corpus cannot measure
whether the directives were necessary. No rows exist without them. The test has to generate
new rows.
