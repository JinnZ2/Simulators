Six-module thermodynamically ordered cascade:

substrate -> insect sequence -> plant succession -> water recovery -> knowledge bridge ->
corridor report

The ordering is the claim: each module's preconditions are the prior module's outputs, so a
recovery program that starts downstream is working against an unmet constraint. Published CC0.
