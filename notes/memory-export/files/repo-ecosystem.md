## Words-are-not-definitions constraint

One level up from slugs-as-gate-keys: where the only available English token was fixed on one
observed instance and carries a later moral or narrative load, **the term routes the question
to the load and the concept becomes unaskable.** Substitution does not clear it — a
replacement word draws the same pushback.

Repos therefore STATE THE OBJECT and accept the wrong word. Pushback has consistently attached
to available wording, not to the stated object.

## Base rate on human-exceptional claims

Human-exceptional claims — most complex language, sole tool user — were held as boundaries,
failed ON MEASUREMENT rather than on better theory, and **the boundary moved instead of the
claim being withdrawn.** The base rate is not favorable.

Position on consciousness follows from that: the claim is UNTESTED, not false. Build the
instrument, run it evenly, report the result.
