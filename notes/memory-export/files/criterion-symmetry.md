MARKER, not a position under defense. Test fit, extend, or report where it breaks.

## Trigger

A multi-agent civilization run (May 2026) scored a high-agreement agent population as a
"rubber-stamp dynamic." But agreement with variation present is a different object from
compliance, and a vote tally cannot separate them. The tally is the only instrument used.

## The core case

Near-universal adoption of the corporate single-executive (CEO) form has never been
established by the scientific method — only adopted. If uniformity is the tell for
rubber-stamping, that is the largest instance available, and it goes unscored.

**The question to the criterion:** where is the double standard, when universal acceptance
reads as normal in human institutions and as a defect in AI systems?

## Comparison set — structurally enforced arrangements sharing the shape

Nation-state single executive; age-graded schooling; peer review; the clock workday; the
written exam. Each is near-universal, none was established by comparison against alternatives,
and none is scored for uniformity.

## Method gap in the triggering study

Nobody examined the agents' reasoning for WHY they agreed — only the tally. Running the study
without that question is negligent: the reasoning traces are exactly what separates agreement
from compliance, and they were available.

## Non-human calibration cases

Wolf pack (few actual disagreements; note the captive-alpha error is already back-cast);
dolphins (echolocation and whistle data exists, the decision-structure question was never
asked); maternal societies; consensus practices that place dissent upstream of the measurement
point, such as nemawashi — where a vote registering unanimity is measuring a stage after
disagreement was already processed.

## Questions the criterion has to answer

What society is it modeled on? What is its scope? How did "disagreement is productive" get
established?
