# memory-export

Backup storage for a memory set exported out of session. Same rule as
`notes/operators/`: files are stored as delivered, and nothing here edits
what it stores.

Nothing here is a simulator. No claim table, no `REFUTATION_PROTOCOL` — a
manifest describes a handling decision, not a result.

## Contents

| file | what |
|---|---|
| `SCRUB_RULES.md` | scrub rules and tier assignment for the public export. 57 tier 1, 7 tier 2, 12 tier 3. |

## What is not here

The manifest landed; the 64 exported files it describes did not. So the
tier counts and the per-file "what was lifted" column are, in this folder,
unchecked against their own subjects.

The 12 tier-3 files are held back by the manifest's own decision and are
not expected. Their absence is a choice recorded upstream, not a gap here.
