# Four dataset uploads, 2026-08-25

Delivered with one instruction: "also have some files for different
datasets to file for future." Not a run. This is the index.

Unlike `mesa_sof.md` beside it, this file is NOT delivered prose. The
operator delivered bytes; this is an index written over them in this
session, so the folder's one rule ("an entry is stored as delivered, a
checker never edits the entry it checks") applies to it differently: the
thing held fixed is the bytes, recorded by hash, and the readings taken
over them are in `notes/FINDINGS_UPLOADS.md`.

The bytes are NOT in this repository. Reason and cost are in the last
section; read it before assuming the files are somewhere in the tree.

Every number below was measured from the uploaded bytes on 2026-08-25 by
`notes/check_uploads.py`, which can be pointed at a re-obtained copy to
check whether it is the same file.

## 1. Practice-Datasets-for-Excel

    sha256  e1d498901b15cc558589c576a433a6fa2a0183f677979aa7603c1f4fd884132d
    size    14326846 bytes
    format  zip, 61 members, single top-level dir Practice-Datasets-for-Excel-main/
    origin  a GitHub repository, MIT, "Copyright (c) 2025 rohanmistry231"
            (from the bundled LICENSE; not fetched from GitHub here)

Fifteen named datasets in twenty-six `.xlsx` files, one folder each, each
folder carrying a `Dataset_Details.docx`. Named in its own Readme:
Superstore Sales, Iris, Titanic, Wine Quality, Adult Census Income,
Boston Housing, Breast Cancer Wisconsin, Online Shoppers Intention, Bank
Marketing, Avocado Prices, Amazon Top 50 Bestsellers 2009-2019, FIFA
World Cup, NYC Airbnb Open Data, World Happiness Report 2015-2019, Stock
Price (Amazon / Apple / Facebook / Google / Netflix).

**Property that decides what this is good for: 26 workbooks, 0 formulas.**

The formula scan returns 3 hits and all three are false. They are in
`New York City Airbnb Open Data/AB_NYC_2019.xlsx`:

    B33569  = modern, a/c, easy check-in / book instantly ==
    B44059  = travelholic rooms (modern decor / clean) ==
    B45795  == happy travels / near columbia university ===

Airbnb listing names that happen to start with `=`, which Excel typed as
formulas on import. A token matched by shape rather than by role -- the
same class as `sheet-structure-scan` SSS_048, where `often times` matched
as multiplication and was caught by the operand requirement rather than by
the operator match. A reader counting `<f>` elements reports three derived
cells in a corpus that computes nothing.

So for `sheet-structure-scan`: every one of the 26 fails WO7 criterion
(c), there is no precedent depth anywhere, scans 2/3/4 and `coupling.py`
have nothing to bite on, and the WO7 screen has NOT been run on them
because the property that would decide it is already measured. These are
flat data tables in `.xlsx` clothing.

What they could serve instead: a corpus of twenty-six real-world column
headers with real dirty values, for anything that reads header text or
companion absence. Scan 2 (companion absence) is the one scan here that
does not need formulas.

## 3. UCI mechanical-analysis

    sha256  efe80d7c384b38518333d4c6e7f9f0333d261440953760d853a7e294077f4a78
    size    1774660 bytes
    format  zip, 9 members, UCI ML repository directory layout with Index files

    Index of mechanical-analysis
    02 Dec 1996      128 Index

Fault diagnosis in electro-mechanical devices from vibration
measurements. Bergadano, Giordana and Saitta, University of Torino, with
Brancadori and De Marchi at Sogesta; donated by Enichem (Eni) Ravenna
through Sogesta (Eni) Urbino, received June 1990. Past usage cited in the
`.names` file: "Integrated Learning in a real Domain", Proc. VII ML
Conference, Austin TX, 1990, pp. 322-329.

209 instances, variable numbers of components per instance, 8 attributes
per component: class (1..6), component number, support (1..4), cpm
(frequency of the measure), mis (measure), misr (earlier measure), dir
(filter / type / direction, nine values from `vo` to `iv`), omega (rpm).
Twelve instances (8, 12, 32, 33, 66, 69, 73, 152, 167, 194, 203, 208) are
held out in `.notused-instances` and the `.names` file says outright that
its author did not know why.

`DISTRIBUTION.Z` is `compress(1)`, not gzip; it has not been unpacked
here.

What it is good for, and it is the only one of the four with a live use:
`mis` and `misr` are the same quantity measured twice on the same
component. That is a *repeat-measure* pair, which is the null
`triad-playground` TP_010 says every shadow-panel and consensus statistic
in this repo is missing -- shadow spread is bounded by what an observer
can repeat, and nothing here has a same-observer repeat variance to
compare against. This dataset carries one, on an instrument, from 1990.
Not run; the sizing question (whether the interval between `mis` and
`misr` is short enough for the pair to be a repeat rather than a trend)
is a G-RES pair and is not answered by the `.names` file.

## 4. World Bank Data Catalog

    sha256  3baefe4d06a597cfece21c499395692a354dc6b766e8dd8eabf6195836271a92
    size    164877 bytes
    format  csv, utf-8 with BOM, 26 columns, 160 data rows

Columns: DataCatalog_id, Name, Acronym, Description, URL, Type, Language
Supported, Periodicity, Economy Coverage, Granularity, List of
Countries/Regions/Sub-National Admins, Number of Economies, Data Notes,
Topics, Update Frequency, Update Schedule, Last Revision Date, Contact
Details, Access Option, Bulk Download, API, Attribution/citation,
SourceURL, DetailPageURL, Coverage, APIAccessURL.

Not data. A catalogue OF datasets -- 160 World Bank collections with
periodicity, revision date, coverage and access route per row.

Two things it is:

(a) A **target list**. `sheet-structure-scan` WO7 S1 asked for a third
    eligible workbook and could not get one, because every publisher host
    tried returns a refused CONNECT under this environment's allowlist
    (SSS_053). This file is a pre-built list of 160 candidates with their
    URLs already in a column. It does not solve the egress problem -- the
    hosts are still not reachable from here -- but it means the selection
    step is no longer the bottleneck, and someone with reach can screen
    from it directly.

(b) A **clock corpus**. `Periodicity`, `Update Frequency`, `Update
    Schedule` and `Last Revision Date` are four fields about the same
    thing, published side by side, 160 times. `fold-matrix` S5 wants
    clocks per level and never collapsed, and `claim-record`'s field 5
    derives a shelf life from a time constant. A published set of stated
    update intervals against stated last-revision dates is a place where
    a stated clock and an observed one can disagree, and the disagreement
    is computable from this file alone.

Neither has been run.

## Why the bytes are not here

Sixteen and a half megabytes across four files, of which 16.1 MB is
binary. This repository is text by construction -- `sheet-structure-scan`
writes its own `.xlsx` fixture with `zipfile` at run time specifically so
no workbook binary is checked in. Landing 14.3 MB of third-party practice
data would be the largest object in the tree by two orders of magnitude
and would carry someone else's copyright terms into a CC0 repo.

The cost is real and is stated rather than waved off: this container is
ephemeral, and when it is reclaimed the bytes are gone. What survives is
this entry. That is why every section carries a sha256 -- a re-obtained
copy is checkable against the recorded hash, size and shape by
`notes/check_uploads.py`, and a copy that differs is reported as
differing rather than assumed to be the same file.

`notes/check_uploads.py --check DIR` was run against the uploads on the
day they arrived and returned PRESENT_MATCH on all four. On its first
run it did not: it reported the UCI member list as differing, because
the record here had been transcribed with six members and the archive
holds seven -- the dropped one being `mechanical-analysis.notused-instances`,
the file section 3 above spends a paragraph on. The record was corrected;
that is what the checker is for, and it caught the error while the bytes
were still on disk to catch it against.

Two of the four are re-obtainable by name from their publishers (World
Bank Data Catalog; UCI mechanical-analysis). The Practice-Datasets zip
names its author in its LICENSE. The EPA extract carries no creator and
no source URL in its metadata -- its origin is inferable from the
`product_url` column and is not recorded in the file itself, which is the
weakest provenance of the four and worth knowing before anyone relies on
re-obtaining it.
