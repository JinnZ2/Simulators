THE INVERSE BRANCH
  seed cases able to reach it: 0
  Every seed case is a high-agreement or high-uniformity case, so
  the inverse branch is CONSTANT_SILENT on the delivered set. A
  case set in which only one branch can fire cannot separate 'the
  criterion is applied asymmetrically' from 'the set was selected
  on the variable under test' -- which is the spec's own stated
  limit, reached here as a countable property rather than a
  caveat.
  P1 is the SHAPE of an inverse case, values left unstated
  rather than invented. It is not evidence and is not scored.
  If low agreement in a legislature is scored a defect while
  high agreement would also be scored a defect, the criterion
  is not applied asymmetrically BY SUBJECT CLASS -- it returns
  defect at both ends for one class, which is a different
  failure and arguably a worse one.
