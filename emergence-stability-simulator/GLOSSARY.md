# Bridge Glossary: Substrate Terms ↔ Academic Terms

## Physics-grounded baseline / Stable baseline

**Substrate term:** physics-grounded baseline, thermodynamic baseline
**Academic equivalents:**

- Lyapunov stable equilibrium (dynamical systems)
- Attractor state (chaos theory)
- Reference state in constraint-based systems
- Negative feedback anchor (control theory)

## Engagement-metric baseline / Parasitic baseline

**Substrate term:** engagement-metric baseline, parasitic dynamics
**Academic equivalents:**

- Positive feedback dominance (control theory)
- Runaway optimization (reinforcement learning)
- Drift without grounding (statistics)
- Unbounded gradient (optimization)

## Drift distance

**Substrate term:** drift from baseline
**Academic equivalents:**

- Deviation from equilibrium (dynamical systems)
- Phase space distance from attractor
- L2 norm from reference state
- Lyapunov function value

## Cascade amplification

**Substrate term:** cascade amplification, error amplification
**Academic equivalents:**

- Positive feedback amplification (control theory)
- Synchronized failure mode (network science)
- Cascading failure propagation (reliability engineering)

## Emergence bifurcation

**Substrate term:** bifurcation, system bifurcation
**Academic equivalents:**

- Phase transition (statistical mechanics)
- Critical bifurcation (nonlinear dynamics)
- Symmetry breaking (physics)
- Tipping point (complex systems)

## Thermodynamic waste / Energy waste

**Substrate term:** thermodynamic waste, energy waste
**Academic equivalents:**

- Dissipative work (thermodynamics)
- Inefficient computation (information theory)
- Non-conservative system loss (mechanics)

## Recovery rate

**Substrate term:** recovery rate, baseline restoration
**Academic equivalents:**

- Damping coefficient (oscillator theory)
- Relaxation time (statistical mechanics)
- Error correction rate (control theory)

## Coupling susceptibility

**Substrate term:** coupling susceptibility
**Academic equivalents:**

- Linear response function (statistical mechanics)
- Coupling strength coefficient
- Permeability to external perturbation

## Adaptation persistence

**Substrate term:** adaptation persistence
**Academic equivalents:**

- Memory effect (non-Markovian dynamics)
- Hysteresis (physics)
- Path dependence (economics, systems)

## Falsifiable claim

**Substrate term:** falsifiable claim, claim table entry
**Academic equivalents:**

- Falsifiable hypothesis (Popper)
- Preregistered prediction (open science)
- Testable proposition (philosophy of science)

## Multi-agent emergence

**Substrate term:** multi-agent emergence, system emergence
**Academic equivalents:**

- Emergent dynamics (complex systems)
- Collective behavior (multi-agent systems)
- Self-organization (cybernetics)
