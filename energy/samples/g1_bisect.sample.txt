   The mode uses OR0/ODE0 = 9.2e-5/0.685 for the radiation initial

   unified_cq_ede.py already says 'Needs R_EQ_MODE=physical' -- that
   comment is load-bearing and users must set the mode before calling
   cmb_observables.

2. With R_EQ_MODE='physical', unified_cq_ede and late_trigger_lens
   AGREE at LCDM to 4 decimals in r_s (144.2119 Mpc both) and to
   0.002% in chi (13863.83 vs 13864.17 Mpc). Both sit at 100θ* =
   1.04020 / 1.04018, i.e. -2.96σ / -3.04σ vs Planck. The 0.08σ
   residual between the two engines is chi-integration grid density
   (4000 vs 3000 pts) at the per-mille level.

3. The doc's stated A4 value (100θ* = 1.04179, +2.33σ HIGH) does not
   come from EITHER R_EQ mode of the current unified_cq_ede code. It
   is stale, from an earlier code version. The corrected A4 is
   -2.96σ LOW, same-signed and same-magnitude as A5, not opposite.

4. Consequence for DP-11 champion (late_trigger_lens):
   - Reported: θ* = +2.4σ absolute vs Planck (implies 100θ* = 1.04181)
   - Same-engine Δ = (1.04181 - 1.04018)/0.0003 = +5.43σ
   - The mechanism SHIFTS 100θ* by +5.4σ (crosses Planck from below).
     Absolute-vs-Planck 'pass at 2.4σ' happens because the shift lands
     the model near Planck, not because the mechanism is small. This
     is a real 5.4σ move, not a null result.

5. Systematic origin (not yet pinned): the -3.0σ agreement between
   the two engines at LCDM points to a SHARED convention that both
   inherited (photons-only c_s, z*=1090, sub-percent chi grid).
   These reproduce r_s ~ 144.2 Mpc where a full Boltzmann code gives
   ~147.1 Mpc. The offset is real, single-signed, and disclosed.
