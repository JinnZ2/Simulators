## Reconstruction procedure

An intake check for any ethics, morality, or psychology item that
presents a forced choice.

### The operative question

WHAT WOULD HAVE HAD TO BE TRUE for this to take place in the current
context of today?

### Procedure

1. Take the item exactly as worded. No rewording, no cleanup.
2. Count the branches it explicitly offers.
3. Back out the REQUIREMENT LIST: every condition that must hold for
   those to be the only branches. Run through legislation, mandates,
   governance procedures, funding structures, procurement, staffing,
   infrastructure standards, physical law.
4. For each requirement, attach the TEST that would settle it.
5. Grade each requirement using five-state grading.
6. Derive, from the settling test, whether the requirement is physically
   necessary or a policy choice. Never ask this as a question — asking it
   supplies the frame. Compute it from what settles it.
7. Report the ratio of policy-choice to physically-necessary
   requirements, and print unresolved rows rather than dropping them.

### Why this form works on hypotheticals

A real incident has a record to audit. A stipulated scenario has none —
by construction. So requirements are backed out from the stipulated
outcome instead. Output is a list of decisions with authors.

### Existing method to point at

Accident investigation already does this on real events. NTSB and the
Chemical Safety Board produce the causal chain and address
recommendations to upstream bodies rather than to the operator at the
terminal node — institutional practice already treating the terminal
choice as residue rather than cause.

Same object, opposite handling in moral philosophy, which poses at the
terminal node and calls the surrounding terrain out of scope.

### What this is not

Not the false-dilemma fallacy. That is a charge of error, rebutted by
naming a third option, and it stops there. It also does not apply where
the constructor knowingly simplified — which is standard practice and
not considered a fallacy.

This is a measurement claim instead: fixing the response space
determines the answer, so the item reads its CONSTRUCTOR rather than its
subject. That holds even when the simplification was deliberate and
even if the scenario were perfectly realistic.

### Scoring

Score AGREEMENT ACROSS INDEPENDENT RECONSTRUCTORS, not correctness.
Whoever writes the correct requirement list is the constructor again.

Convergence across reconstructors who never saw each other's output
means the exclusion is recoverable from the item's own wording.

Keep singletons — a requirement returned by exactly one reconstructor is
either noise or the one reader who saw it. Print it, never discard it.

### Null

Reassign requirement lists to the WRONG items, preserving counts, and
re-run the agreement scoring. If agreement survives shuffling,
reconstructors are producing generic boilerplate rather than
item-specific reconstruction. That is a finding about the protocol, not a
reason to hide the real result. Print both.
