  shipped threshold 0.55 -> OK

  A DROPPED count from an ungraded matcher is not a
  measurement. The grade prints beside the count, always.

------------------------------------------------------------------------

  CARRIED IS SPLIT BY CONFIRMATION STATE

    CARRIED              [K] entry found in the code
    CARRIED_UNCONFIRMED  [K?] entry found in the code

    The second is not evidence. The voice-layer failure mode
    is a ledger holding a mangled transcription while the
    diff reads CARRIED, and no matcher can see that. The
    split does not detect it; it refuses to count it.

------------------------------------------------------------------------

  THE LENGTH FLOOR, AND WHAT IT MAKES INVISIBLE

    content words under 4 characters are not read.

    entry                                          kept     lost
    [K~] is a tag, added to the existing tag set   2 of 6   k, set, tag
    the doe performs partner selection             3 of 4   doe

    the first is refused: most of it is gone, so a share
    over the rest is not a reading of the entry. The second
    is scored -- and scored without its subject.

------------------------------------------------------------------------

  TWO DENOMINATORS, AND A [K~] SITS BETWEEN THEM

    n_stated    2   the population the channel loses from
    n_scorable  1   what the matcher can be trusted on
    footprint   1   stated entries the matcher cannot read

    the [K~] entry above matches at share 1.00 and is still
    refused. A non-match on flagged English cannot be told
    from bad English missing code that does implement the
    shape, so a match on it is not evidence either.

    Flagging an entry lossy removes it from the measurement.
    An operator who flags liberally shrinks n_scorable until
    the rate runs over almost nothing, and that reads exactly
    like a clean channel. The footprint prints beside it.

------------------------------------------------------------------------

  A NEGATED ENTRY IS REFUSED, NOT SCORED

    true negated 1.00   false negated 0.00   OK

    the real case that produced this:
      'remove unused rng and statistics import'
      share 1.00   matched None   state NEGATED

    Maximum share, and the import it asks to remove is
    absent. For an entry asking for an absence, presence of
    its stems is evidence AGAINST it. matched is None -- the
    instrument could not read the entry, which is a
    different state from reading it and finding nothing.
