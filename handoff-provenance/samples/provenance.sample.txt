  THE RE-READ COLUMN -- TWO ENTRIES, NEVER SUMMED

    SHIFT     item reads differently later; observing position moved
              measures: the station
              prior diff: STALE_NOT_WRONG. The item changed, so a prior
              verdict was about a different item. Re-run the diff; the
              old one was not an error

    RETRANS   item reads the same, English was wrong the first time
              measures: the translation layer
              prior diff: POSSIBLY_FALSE_CARRIED. The item did not
              change, so a prior verdict was taken against wrong
              English. If it read CARRIED it may have been the fourth
              failure mode

    unchanged-text re-read: REFUSED (unchanged = a confirmation)
    unattributed re-read:   REFUSED (shape question is upstream)

    Both kinds produce ONE observable: the line changed.
    Which one it is depends on whether the SHAPE moved, and
    that is not in the text. RETRANS is the only route by
    which the spec's fourth failure mode ever surfaces here,
    and it surfaces as a LOWER BOUND, never a measurement:
    only what the operator re-read and caught is counted.
