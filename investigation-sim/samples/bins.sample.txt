INVESTIGATION SIM -- foreknowledge bins
CSB-style investigation across industrial, manufacturing
and infrastructure. SPEC.md is parsed, not restated.

Every case here is CONSTRUCTED. Egress from this environment is
an allowlist and every incident-report host is outside it, so
nothing in this folder reads a real report or says anything about
a real event.

0. THE SELECTION TRAP
   Every case in an incident-report corpus is a case where
   something happened, so a classifier run over one will find
   foreknowledge. rate() raises rather than returning a number.
   The mode that escapes it is FORWARD, whose frame is chosen
   before any outcome -- which is also the mode the tool is for.

1. THE BINS
     KNOWN_ROUTED_AWAY      -> report-typing
     CALCULATED_UNCLOCKED   -> claim-record, criteria-drift
     CONCEIVED_NOT_BUILT    -> fold-matrix
     GAP_UNINSTRUMENTED     -> uninstrumented
     NOT_FORESEEN           -> (the negative)
   not bins: NOT_DERIVABLE, MULTIPLE
   NOT_DERIVABLE is not NOT_FORESEEN. One says look harder, the
   other says stop looking, and a scalar collapses them.

1b. THE ONE WIRED ROUTE
   The routes above are DECLARED. GAP_UNINSTRUMENTED is WIRED: a
   case firing it names which of the register's exclusion
   mechanisms applies, refusing anything outside that vocabulary,
   and the vocabulary is imported rather than copied so the two
   cannot drift.
     gap-uninstrumented         DECLARED                 STORAGE
   the other four routes are declared and not wired. That
   is the folder's largest open item and is IS_008.

5. WHAT IS REFUSED
   rate() raises: A rate over a corpus selected on the outcome
   has no denominator. Every case in an incident-report corpus is
   a case where something happened, so the population of hazards
   carrying the same signature and no event is uncounted
   (generation-capacity R4). Run FORWARD mode instead: its frame
   is chosen before any outcome.
