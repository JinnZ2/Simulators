ALTERNATIVE PREDICTOR -- does the module RUN what it finds

  census.py did both, and enumeration was not why.
  Reading a tree cannot change it; running what is in the
  tree can, and its writes were its children's. So the
  same 2x2 against `executes`:

                       writes: yes   writes: no
  executes yes                   3           16
  executes no                    0           30

    of 19 that execute or write by design, 3 write  (16%)
    of 30 that do not,                     0 write  (0%)
    difference: +16 points

  This is a WEAKER test than the first: `executes` is read
  from the source and `writes` is observed, so a module
  that opens a file for writing is close to predicting
  itself. It is reported for the contrast with the
  enumeration column, not as an independent finding.
