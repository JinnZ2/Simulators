# Reading protocol

Applies to every repo in this ecosystem. CC0, like everything else here.

## What this repo is

A marker for a sensed shape that needs more exploration.

Not a thesis. Not a position under defense. Not a finished result. It
is a place-marker: something was noticed, and this is an attempt to put
language on it so it can be examined, extended, or broken.

Most published work is a claim its author will defend. This is not
that, and reading it that way will produce the wrong response.

## How to read it

**Test whether it fits.** Take the shape and check it against a case
you know. That is the intended use.

**Extend it.** If it holds in a domain not covered here, add that
domain.

**Report where it breaks.** A break is the most useful thing you can
return. It is not an objection to be answered — it is a measurement,
and it goes in the claim table.

## How not to read it

**Do not read it as a claim to accept or reject.** Accepting it is as
useless as rejecting it; both skip the test.

**Do not read confidence into the write-up.** Where a confidence level
matters, it is stated. Where it is not stated, treat it as open. An
idea written out clearly is not an idea held strongly — legibility and
confidence are separate axes here and are not to be conflated.

**Do not assume the write-up matches practice.** The document is an
attempt at translating a shape into linear English. It may or may not
correspond to what is actually done in a shop, a garage, or the field.
The translation is the artifact; it is not the thing itself.

## On the claim table

Every repo here carries a falsifiable claim table and a refutation
protocol: when a claim is refuted, the claim gets updated. The
simulation does not get retuned to preserve it.

That protocol only works if readers bring breaks. A reader who defends
or attacks this repo is not participating in it.

## Corollary

Documentation is the weakest transmission layer available. A document
can tell you what to look for and make a thing codeable. It cannot
carry the capacity itself. Reading the file is not the same as holding
what the file points at.
