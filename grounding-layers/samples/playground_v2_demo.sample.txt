── Observation flagged for the next iteration round ─────────────────
"I can lift 200 kg" passes as grounded. This is because the L0 branch
routes mass to `apply_physics`, which internally clips force to ±50 N
and caps velocity at max_speed — so the resulting state is always
valid regardless of input mass. Neither L0 (via `is_valid_state`) nor
L4 (which currently only checks speed) catches this claim.

Faithful to the draft in organize.md; this discrepancy is a design
question for the next round. Two candidate fixes:
  - Add a `lift_mass` check to the L4 branch (route mass to L4's
    lift_mass distribution: mean=35, std=15, so 200 kg falls
    outside the 95% CI and gets rejected as a human limit).
  - Change the L0 branch to check the RAW (unclipped) force
    against a physical impossibility threshold, not against
    apply_physics's clipped output.
