## TC_006 -- why the material floor is required

The order asks whether transmission type "adds nothing" once
identification-with-leader is entered. The natural test is whether the
type coefficient collapses when identification is added. But a
relative-collapse test passes trivially in the world where type never had
an effect: both the type-alone and type-with-identification coefficients
are noise near zero, their ratio is near one, and the sign agrees, so
"survives" fires on a null. The fix is an absolute floor: type survives
only if its coefficient stays material (|b| >= 0.10) with identification
entered. On the two constructed worlds the type-null coefficient is about
0.02, below the floor, and the type-real coefficient is about 0.42, above
it, so the floor is exactly what separates them. Without it R4 is
`null-harness` `CONSTANT_FIRES` -- a competing-explanation test that never
credits the competitor.
