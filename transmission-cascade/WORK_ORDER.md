the deliverable.

## LITERATURE A — ORGANIZATIONAL TRICKLE-DOWN / CASCADE

```
HAS:      depth. Behaviour cascading level to level ("falling domino").
          Three-level models tested. Grounded in social learning theory.
MEASURES: outcomes — social loafing, task performance.
MODERATOR: identification-with-leader — whether the subordinate treats
          the manager as a role model.

WHAT IT LACKS: the moderator is a POSTURE variable. It codes how much
          transmission happened. It does not code WHAT MOVED.
```

## LITERATURE B — CULTURAL EVOLUTION / SOCIAL LEARNING

```
HAS: the transmission-content taxonomy Literature A is missing.

  STIMULUS ENHANCEMENT  attention directed to an object or location
  EMULATION             the RESULT is copied; the behaviours producing
                        it are not
  IMITATION             the specific behavioural MEANS are reproduced
  OVERIMITATION         ALL steps copied faithfully, without
                        understanding why any step is necessary

EVIDENCE BASE: toolmaking, children's game transmission, primate
          comparison.
FIELD'S OWN STATEMENT: how far these mechanisms produce distinct
          patterns of variation remains largely unexplored empirically.
```

## THE UNJOINED SEAM

```
Nobody has coded a multi-level leadership or rule cascade
by TRANSMISSION TYPE.
```

**Why it matters, and why OVERIMITATION is the load-bearing construct.**
Overimitation already names two things that are otherwise described
separately and informally:
```
- the procedure-follower who executes steps with no access to why
- the driver pacing off surrounding traffic rather than off the sign
```
Both are "copied steps without the generating principle" — a named,
studied construct sitting unused in the organizational literature.

**The prediction that makes it testable.** The four transmission types
should behave differently in two measurable ways:
```
1 DECAY ACROSS LAYERS
  copied-result and copied-steps transmissions should degrade at
  different rates layer to layer

2 DIVERGENCE UNDER CONDITION CHANGE  <- the decisive one
  at the far layer, a copied-steps transmission HAS NOTHING TO
  RECOMPUTE FROM. An emulation or principle transmission does.
  Under stable conditions all types look alike. They separate only
  when conditions change.
```

## RUNNABLE

```
R1  RECODE AN EXISTING DATASET
    Take a published three-level cascade dataset. Code each transmission
    event by type (stimulus enhancement / emulation / imitation /
    overimitation) rather than by outcome magnitude.
    NO NEW DATA COLLECTION. This is the cheap entry point.
    OUTPUT: distribution of transmission types by layer.
    Even with no further work, "which types appear at which layer"
    is a result nobody has.

R2  CODER RELIABILITY FIRST
    Before R1 produces anything citable: two independent coders,
    blind to layer and to outcome, agreement reported.
    If the taxonomy cannot be applied reliably to organizational
    behaviour, R1 is uninterpretable and THAT is the finding.
    Run R2 on a subsample before committing to R1.

R3  CONDITION-CHANGE PROBE AT THE LOWEST LAYER
    Introduce a change that makes the transmitted behaviour no longer
    serve its original purpose.
    MEASURE: who recomputes, who repeats.
    Cross-reference the transmission type coded in R1.
    PREDICTION (PROPOSED): overimitation-coded chains repeat;
    emulation-coded chains recompute or fail visibly.
    If type does not predict the response, the taxonomy does not
    transfer and R1's value is descriptive only.

R4  IDENTIFICATION-WITH-LEADER AS A COMPETING EXPLANATION
    Literature A's existing moderator must be entered alongside
    transmission type, not replaced by it.
    If identification alone predicts the R3 outcome, transmission
    type adds nothing. Test it, do not assume it.
```

## SCOPE LIMIT — STATED, NOT SMOOTHED

```
Literature B's evidence base is CHILDREN AND TOOLMAKING.
Transfer of its taxonomy to adult organizational hierarchy is
ITSELF UNVALIDATED and must not be assumed.
```

R2 is where that limit gets tested. If the taxonomy will not code adult
organizational transmission reliably, the correct output is a statement that
the taxonomy is domain-bound — which is a useful result for Literature B and
costs one subsample to obtain.

---

## WHY THE SEAM EXISTS

Neither field is failing at its own task. Literature A measures how much
moved because its outcome variables are organizational performance.
Literature B built the content taxonomy because its cases are learning
episodes with visible steps. The join belongs to neither, so nobody is paid
to hold it — the standard condition for seam-located work.
