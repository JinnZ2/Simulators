## The frame-cycle

Four frames read over the same evidence:

- **Agronomic.** Field-level: symptoms read as drought, compaction, or
  phosphorus deficiency first, because those are commoner and the
  signature overlaps.
- **Entomological.** Vector-level: range is set by host continuity
  across winter.
- **Climatic.** Warming raises the summer thermal envelope and softens
  winters.
- **Hemispheric / logistic.** Corn exists somewhere in the Americas in
  every month; vectors move on weather systems.

## Dissonance rows

| id | where two frames disagree | status |
|---|---|---|
| **D1'** | **The agronomic and entomological frames disagree on *when the event happened*.** Agronomic reads the damage as concurrent with the symptoms. Entomological puts the causal event ~6 weeks earlier. So any field record dated to symptom appearance **mis-dates the event by the sum of two lags** — and any correlation of the outbreak with weather in the symptom window is correlating against the wrong window. | DERIVED from the carried lags; the arithmetic is the whole claim |
| **D2'** | **"Warming expanded the range" and "winter host availability sets the range" predict different shapes.** Warming predicts gradual northward creep. Host availability predicts a jump wherever a host ladder appears. What was reported in 2024 reads as a jump. This favours the host explanation and is checkable against prior-year detection maps. | HYPOTHESIS; the shape claim rests on UNCERTAIN detection geography |
| **D3** (pass 1) | A **US second-season / irrigated host ladder** — corn hosts available later than the rain-fed main crop, bridging a gap the main-crop calendar does not explain | HYPOTHESIS, carried forward unchanged |
| **D4'** | **No frame in use spans both hemispheres.** Argentina 2023/24 and the US 2024 are a year apart and in opposite seasons, which is to say roughly *continuous* host availability if you count both. Each is read as a national event. The hemispheric frame reads them as one host-continuity question. **Nothing here establishes any link** — the dissonance is that no one's frame is shaped to ask. | GAP IN FRAMING, not a claim about transmission |
| **D5'** | **Detection effort is confounded with occurrence, and the available records cannot separate them.** Argentina's outbreak raised US scouting for *D. maidis*. So 2024's northern detections are part looking-signal and part occurrence-signal. **This row undercuts the pass**, including D2's jump shape, and it is the row the method is most for. | SUPPORTED as a confound; unresolvable without G4' |

D5' is the honest centre of this pass. A method that returns four
dissonances pointing one way and one pointing at its own instrument is
working; one that returns only the four is not.
