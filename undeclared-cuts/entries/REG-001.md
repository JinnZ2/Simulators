measurand: For each row absent from a record where a record exists, the SHAPE of the harm that follows from the absence, read on three declared axes: irreversible or recoverable, concentrated or diffuse, fast or slow. The unit of the register is the MECHANISM by which the absence produces the harm, not the incident, the organisation, the dataset or the decision.
control: Rows present in the same register carrying the same three axes, so the axes are exercised on filled rows before any absence is read. Second arm: mechanisms whose harm shape is established outside this register (a documented recall, a documented reversal) which fix the axis values independently of the register's own coding.
scope_limits: Numerator only. The register counts missing rows that can be located; the denominator -- rows that should exist -- is not constructible, so every count is reported as a FLOOR and no rate, share or percentage is emitted. Unit is the mechanism, so one incident may contribute several rows and several incidents one row; the count is not a count of events. The three axes are read per mechanism, and a mechanism whose axis value depends on where the harm lands is recorded as SPLIT rather than assigned. Says nothing about likelihood, and nothing about whether a given absence has in fact produced harm.
thin_links: Assigning a harm shape to an absence is an inference over an inference: the harm is inferred from the mechanism, the mechanism from the absence, the absence from the register's own scope statement. Each hop is marked per row and a row missing any hop is recorded as UNSHAPED rather than given a default. Reading a closed row as resolved is a further thin link and the CLOSED-ON-TRACTABILITY row type exists to keep it out of the count.
would_change: A constructible denominator for any row class turns that class's floor into a rate and the entry records the class, the denominator and its source. A mechanism whose documented outcome contradicts its coded shape moves the row and the coding rule is revised, not the row. An independent register covering the same mechanisms would bound the floor from above for the overlap. Evidence that a CLOSED-ON-TRACTABILITY row was closed on a finding rather than on cost re-types the row.

## The mapping

```
    a row is absent
          |
          v
    MECHANISM          how the absence reaches a consequence
          |
          v
    HARM SHAPE
      irreversible  /  recoverable
      concentrated  /  diffuse
      fast          /  slow
```

Three binary axes, read independently. They are not summed, not
weighted and not collapsed to a severity. A row carries three values or
it carries UNSHAPED.

## Row types

```
    DELIVERY                  the row is absent because the thing that
                              would fill it was never delivered --
                              the obligation exists, the artifact does not

    CLOSED-ON-TRACTABILITY    the row was closed because filling it was
                              judged too hard, expensive or slow, not
                              because the question was answered. A closed
                              row that reads as resolved and is not.

    (further types are added as the register meets them; a row whose
     type is not one of the declared set is recorded UNTYPED and kept)
```

CLOSED-ON-TRACTABILITY is the type the register exists for: the record
shows a closed row, and closure is what a downstream reader sees.

## Floor, not rate

The register can find missing rows. It cannot enumerate the rows that
ought to exist, because that enumeration is the thing whose absence is
being registered. Every output is therefore:

```
    at least N mechanisms of shape (axis, axis, axis)
```

and never `N of M`, never a percentage, and never a trend.

## The two-clock caveat

The clock on which the harm arrives and the clock on which the row could
have been filled are different clocks and the register does not align
them. A row fillable in a month against a harm arriving over decades,
and a row fillable in a decade against a harm arriving in a week, both
read as one missing row. The FAST/SLOW axis reads the harm clock only.
Any statement of the form "this was preventable" requires both clocks
and the register supplies one.

## Not in scope

Assigning responsibility for any absence, and ranking mechanisms against
each other. The register carries shapes; it holds no ordering.
