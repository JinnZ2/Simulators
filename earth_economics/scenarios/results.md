Anomaly Systems What it reveals Framework gap
OCDI deeply negative (< -0.5) Potlatch, Ubuntu, Aboriginal, Sámi, Ainu, Open Source Extraction is not just absent; it is structurally inverted. Value flows out of potential accumulators and into the collective. OCDI as defined assumes extraction is the default state and maintenance is the counterforce. A negative OCDI means the system is regenerative by design. We need a Regenerative Index (RI_gen) that measures how much value is deliberately circulated back.
RPI deeply negative (< -2.0) Aboriginal, Ainu, Sámi Efficiency improvements produce more sharing, not more extraction. The Jevons dynamic inverts. RPI assumes extraction rises with efficiency. In these systems, d(er)/dt is always ≤ 0 regardless of efficiency. We need a Regenerative Phase Index that detects when efficiency drives outward flow.
VE_VL negative Potlatch, Open Source Value extraction is not just low; it flows from capital holders to labor. The equation VE/VL assumes capital extracts from labor. When labor extracts from capital (or when the distinction collapses), the ratio is negative. We need a Value Flow Direction (VFD) metric that doesn't assume polarity.
SC < 500 (Dunbar-limited) Ubuntu, Aboriginal, Ainu, Sámi, Potlatch All relational-primary systems have a scale ceiling. They don't fail at scale; they choose not to scale. The framework's assumption that economies grow is a feature of extraction-based systems. We need a Scale Ceiling Index (SCI) that measures the energetic cost of scaling a relational system vs. the benefit.
BEI near zero All indigenous systems Coordination cost is effectively zero because coordination is embedded in daily practice and ritual, not layered on top. BEI was built to detect bureaucratic overhead in state systems. We need a Coordination Embedding Index (CEI) that distinguishes between administered coordination and embodied coordination.
RTF = 1.0 with non-human persons Ainu, Aboriginal Relational trust extends beyond humans. The concept of "enforcement" doesn't apply because obligation is ontological, not contractual. The framework's trust dimension is human-centric. We need a Non-Human Relational Index (NHRI) for systems where economic partners include rivers, animals, and spirits.
DI low but not zero Ubuntu, Aboriginal, Sámi, Ainu Authority is distributed but not egalitarian in the Western sense. Elders hold more weight, but their authority is earned through relationship, not coercion. DI measures variance in decision-making power but doesn't distinguish between coercive authority and relational authority. We need a Relational Authority Index (RAI) that measures the degree to which authority is granted vs. taken.
UFR negative but variable All gift systems Wealth flows downward, but at different rates depending on the ceremony cycle. UFR was built for continuous extraction. We need a Pulse Redistribution Index (PRI) that captures episodic/ceremonial wealth flows (potlatch, ritual feasts, seasonal sharing).
ISR = ∞ but no inflation All indigenous systems Full collective subsidy of infrastructure without the inflationary pressure of fiat money. The framework assumes infrastructure subsidy is paid through taxation or inflation. We need an Embedded Infrastructure Index (EII) for systems where infrastructure is maintained by the same relationships that constitute the economy.

Immediate next steps: new indices

These ten anomalies demand at least five new indices. I'll draft definitions for the three most critical ones now:

1. Regenerative Index (RI_gen)

```
RI_gen = (Value Deliberately Recirculated) / (Total Value Produced)

Range: 0 to 1
0 = all value retained by producer (capitalist limit)
1 = all value given back (pure gift limit)
```

Captures the Potlatch/Ubuntu/Ainu dynamic. Complements OCDI; where OCDI measures extraction, RI_gen measures regeneration.

2. Value Flow Direction (VFD)

```
VFD = sign(VE/VL)

+1 = capital extracts from labor (extraction)
 0 = balanced or no distinction
-1 = labor extracts from capital, or value flows from holders to community (gift)
```

Replaces the polarity assumption in Equation 1.

3. Scale Ceiling Index (SCI)

```
SCI = N_max / N_current

Where N_max is the maximum sustainable network size before relational trust
converts to institutional trust (measured via Dunbar limits, communication
cost, and coordination energy).

SCI > 1: system operating below its scale ceiling (healthy)
SCI < 1: system has exceeded its scale ceiling (brittle, requires institutional coercion)
```

This is the metric that explains why relational systems choose not to scale, and why institutional systems must become coercive past a threshold.
