4. WHAT THE FALSIFIER COMPARES
   the key is (move, verdict). Blocker, unblocker and
   evidence_locator are not compared, so two runs reaching
   the same verdict for different stated reasons read as
   stable. Whether that is right depends on whether the
   claim is about the finding SET or about the finding.
   The docstring says finding SET, so this matches, and
   the consequence is that the harness cannot see a run
   that arrived by a different route.
