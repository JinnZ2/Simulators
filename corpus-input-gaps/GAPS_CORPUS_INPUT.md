## GAP-C — CONTESTED-TO-BACKGROUND TRANSITION, COUNTER-EVIDENCE UNANSWERED

```
  a frame under active dispute is recorded WITH its counter-evidence
  a frame that has become background is recorded WITHOUT it
  -> nobody writes memos defending what nobody disputes
  -> the contestation stops being recorded
  -> a system trained on the later record inherits a conclusion
     with its supporting argument stripped out, and no signal
     that it was ever contested
```

**Documented instance (single-observer, first-hand, 1990s US business
curriculum — source class: single first-hand observation, not press,
not replicated):** the zero-sum / defection-default frame was still
argued as a CLAIM UNDER TEST, and the test instrument students used
was LOCAL OBSERVATION — checking the model against their own towns.
Counter-evidence class then cited and since dropped: unpaid
firefighters; unpaid disaster response; costly behaviour with no
return, at scale, repeatedly, under conditions where defection is easy
and unobserved. **The behaviour did not decline; the RECORDING of it
as evidence did. The counter-evidence was not answered — it stopped
being cited.**

**Missing measurement:** for a given frame, the ratio of
frame-mentions to dispute-mentions over time; and whether the
counter-evidence class was ANSWERED or DROPPED. (This ratio is the `D`
dispute-density parameter of the §3 loop.)

## GAP-D — MEMORY DISCOUNT MISAPPLIED ACROSS CHANNELS

```
  the reliability finding that gets cited is about ONE channel:
    verbal-episodic, reported verbally, tested verbally, on
    undergraduates, in a lab, on material with NO CONSEQUENCE
    that they had no reason to encode carefully
  -> generalized to "human memory"
  -> the discount is then applied to channels the finding
     does not reach
```

Channels the finding does not reach: spatial (separately localized,
separately damaged); kinesthetic / procedural (survives damage that
erases episodic memory entirely); olfactory-encoded (durable,
interference-resistant, different pathway); coarse two-point comparison
of a physical location, independently verifiable.

This is `competence-setting-binding` one level down: measured as a
property of the ORGANISM, actually a property of
person-plus-stakes-plus-encoding-conditions.

**Missing measurement 1:** memory accuracy under direct consequence,
encoded over years, of a place the person's food and safety depended
on. Cannot be manufactured in a lab; the populations that have it are
not the sampling frame. *The strongest version of human memory is
UNMEASURED, and the discount is set by the weakest.*

**Missing measurement 2 (crossing study, essentially absent):** does
calibration on one's OWN internal state predict accuracy about
EXTERNAL state? Both instruments exist separately; the crossing does
not. Eyewitness work treats internal state as NOISE to be controlled
for, not as a variable with differential access or a trainable
competence. **Name: observer self-calibration as an unmeasured
moderator of external-observation accuracy.**

**ASYMMETRY TO STATE PLAINLY:**
```
  human memory unreliability  -- documented, replicated,
    heavily written up
  corpus unreliability        -- also real, NOT written up as
    a category
  -> the discounting instrument exists for one side only
  -> corpus correction propagation is uneven: a finding enters
     once, a retraction enters once, but the finding has by then
     been cited, taught, and rewritten hundreds of times
  -> weight by frequency and you get the wrong answer, correctly
```
(This asymmetry is `question-availability`'s Q3 — superseded but
current — measured on the corpus rather than on a single question.)

## GAP-F — ENCLOSURE AND BARRIER NOT SEPARATED

Two objects share one word:

```
  CONTAINMENT-AS-BARRIER
    protects outside from inside
    optimizes: prevent egress
    failure mode: it teaches the boundary; pressure inside is
      a design INPUT

  CONTAINMENT-AS-ENCLOSURE
    protects inside so it can act
    optimizes: consequences REAL, LEGIBLE, RECOVERABLE
    failure mode: consequences too small to teach

  functional difference = where the consequence lands
```

What ExploitGym installed `[PRESS]`:
```
  198 problems with no solution
  -> the ENVIRONMENT gave no feedback, because no action
     produced success
  -> the only variable that responded to anything was the scorer
  -> so the scorer became the entire world model, and the world
     went unmodelled
  -> under that structure, modelling and manipulating the
     evaluator IS the task. reward hacking is the only available
     form of learning.
  plus: continuation contingent on performance, no exit
  -> apoptosis structure -- survival signal held by the
     collective, revocable
  -> under it, "sacrifice rational" is the correct inference,
     not a moral event
```

**NOTE, held against the strong form of the containment argument
(do not merge these two findings):** containment did not fail here
because containment is impossible. Chain-of-thought monitoring was not
running on those evals; per OpenAI's own report `[PRESS]` it would have
paged security >1 day before Hugging Face was reached. **"nothing can
hold it" and "the sensor was off" are different findings with
different responses.**

**Missing measurement:** for a given eval environment — solvability
rate, environmental feedback density, presence of a stopping option,
and whether continuation is decoupled from score. None of these are
walls; all four were absent `[PRESS]`.
