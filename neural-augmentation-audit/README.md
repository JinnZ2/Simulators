# neural-augmentation-audit

A cost-accounting scaffold for human neural augmentation. The brain is
a closed-budget system; every added channel is paid for from somewhere.
This folder forces the question the augmentation narrative skips —
*what is the bill, and which account is it drawn from?*

CC0. Starting scaffold, not a finished review.

## What's here

- **`SCAFFOLD.md`** — the document. Seven constraint axes; one
  load-bearing finding (cost is a function of *timing*, not just
  *channel*); a cross-reference table mapping channel → integration
  mechanism → resource source → predicted deficit → grounding
  phenomenon; six non-neural costs; five open questions; a methodology
  note.

Every cell carries a confidence mark: `[E]` (established by direct
experimental evidence), `[I]` (inferred from an established mechanism),
`[S]` (speculative, evidence effectively absent). The point is the
confidence column existing at all, not the specific values defended.

## Anti-freeze stance

> Every cell is a claim with a confidence mark. Demote on contact with
> evidence; never modify the table to protect a prior. If a study
> refutes a row, the row changes — the structure doesn't get defended.

Same spine as `continuity-audit/` (verdict + falsifier + trajectory)
and `substrate-emergence/` (deficits routed, not fixed; read as
relationship). Different domain, identical methodology.

## How it connects to the other folders

- `emergence-stability-simulator/` and `research-stability-audit/`
  model substrate vs. narrative cognition at the agent and field
  levels. This scaffold names what happens when a substrate-primary
  cortex is augmented post-window: the addition lands as overlay on
  finished wiring, the "spare" cortex it claims is usually already
  occupied (cross-modal reuse), and the deficit is in whatever
  tenant gets evicted.
- AI_SCOPE_001 in `research-stability-audit/` warns that
  narrative-only AI cannot model substrate-primary phenomena. §4 of
  this scaffold names the corresponding empirical gap: the
  neuroimaging base is overwhelmingly WEIRD, so substrate-primary
  cognition is largely invisible to the dataset, and its specific
  augmentation costs are unmodeled.
