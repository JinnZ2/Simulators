THE FIVE SITES (unfreeze the zero top-down term in the standard
feedforward update; treat the feedforward equation as a snapshot taken
at one setting of the environment, not a fixed fact; run the inverse
move — ask what conditions make the loop do work, not what it computes):

1. STABILITY CONDITIONS — which gain / timing / input-statistics
   settings hold a feedback loop at a fixed point vs. push it into a
   regime pure feedforward cannot reach. Gradient as a design variable,
   not a given.

2. COMPRESSION PAYOFF — predict the input top-down, transmit only the
   mismatch (residual) upward. Bits spent = -log2(probability the model
   assigned to what actually arrived). Better prediction -> fewer bits
   -> lower cost. This is the predictive-coding/arithmetic-coding
   frontier; the savings are the point, not a side effect.

3. DORMANT-FACE COST — a loop that has settled near a fixed point can
   leave most of its structure quiet and only activate the parts the
   current input actually couples to. Repeated exposure to the same
   input class should get cheaper over time as the loop re-settles
   faster.

4. LANDAUER / ERASURE JOIN — standard feedforward nets discard (erase)
   intermediate activations at every stage; that erasure is where the
   Landauer bound bites. A loop that retains its state and can recover
   earlier values is not standing on that erasure floor. Site: does a
   retained-state loop actually show measurably lower erasure cost than
   an equivalent feedforward pass, or does it just move the erasure
   elsewhere?

5. INVERSE-DIRECTION REUSE — a relation has no privileged direction. Can
   one trained loop run forward as recognition and backward as
   generation, instead of requiring two separately trained networks?
   What is lost/gained running the same weights both ways?

6. REDUNDANCY / GENERALITY / MAINTENANCE FRONTIER — does adding a
   second carrier (a redundant copy of stored information) cost
   generality, and does the trade have a shape once the cost of
   maintaining the copies is counted?
