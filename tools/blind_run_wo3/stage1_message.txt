HONEST EDGE TO CARRY INTO THE RUBRIC, NOT AROUND IT "Reversible" in the
physics sense (Bennett 1982: measurement can run without erasure cost;
the unavoidable cost is paying to erase the record) is NOT automatically
the same as "bidirectional" in the network sense (a net that merely has
connections running both directions). A net can pass signals both ways
and still erase information at every step. The payoff on sites 2-5 only
lands if the loop actually RETAINS and CAN RECOVER state, not merely if
it has feedback connections. Any fruitfulness score must check for this
distinction explicitly, not assume it.
