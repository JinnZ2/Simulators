So every row is read at search-index or secondary depth. No row is at
primary depth. A full-text read would raise the depth of every row and is
owed (section D).

The four-state rule is derived from four recorded observations, never
typed:

```
reached  any channel to the source answered        Y / N / ?
queries  searches run for this claim               count
exists   the source is at the cited ID             Y / N / OTHER / ?
says     the source says what the report says      MATCH / DIFFERS / UNSEEN

exists OTHER                        -> NOT FOUND   (ID resolves elsewhere)
exists N, queries >= 2              -> NOT FOUND
exists N, queries < 2               -> UNREACHABLE (one empty search is
                                                    not a check)
reached not Y, or exists ?          -> UNREACHABLE
exists Y, says MATCH                -> VERIFIED
exists Y, says DIFFERS              -> CORRECTED   (found value required)
exists Y, says UNSEEN               -> UNREACHABLE (the source is there;
                                                    the figure was not seen)
```

A row the rule cannot classify is refused and named, never dropped.
Opaque identifiers (an OSTI number, a ScienceDirect PII) that a search
engine does not index read `?`, not `N`: a search that cannot index the
identifier cannot show it absent.

Load-bearing means: the report attaches a number, a date, a name or a
quotation to the source and uses it; or the citation carries a step of the
central argument (the thermodynamic and retention argument of P section 6,
the four-test battery of C section 4); or it is a candidate anchor for
Part C. The other 39 links are listed in A.10 as context and not checked.
Nothing is silently dropped: every link in both reports appears there.
