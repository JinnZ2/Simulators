# Sensor coupling across substrates - skeleton baseline

CC0. Status: SKELETON. Co-authored, Kavik + Claude, 2026-11-23.
Every citation below is from model knowledge, not checked against the
source: tag DERIVED, volume moderate, until verified. Every measure is
untested. VOID = not yet known; never filled from recall.

## 0. Claim (PROPOSED)

Any system - biological, computational, social, governance - can only
be steered as well as its sensors see it. Decoupling the people or parts
nearest a process from decisions about it removes sensors; cascade risk
rises. Burden of proof: a claim that humans or institutions are exempt
from biological feedback rules needs its own evidence.

## 1. Common denominator

- energy (J, W): what a process costs and can sustain
  anchors: Landauer 1961 (min energy per bit erased); Kleiber (metabolic
  scaling); Bettencourt/West 2007 (urban scaling); EROI (food system
  roughly 7-10 fossil kcal per food kcal)
- structure, recorded beside energy (same energy, different arrangement:
  forest vs woodpile): VOID - measure not chosen

## 3. Measures (all untested)

    detection_lag      time from first ground report to decider action
    report_rate        reports per unit time, per sensor population
    suppression_gap    problems found after failure minus problems
                       reported before it (bigger gap = silenced
                       sensors)
    requisite_variety  sensed variety vs system variety (Ashby 1956): VOID
    energy_return      output energy / input energy, per boundary

Each: units, data source, test design = VOID until a run.

## 4. Worked anchors (DERIVED, from model knowledge)

- Ostrom (Nobel 2009): local users often manage commons better than
  distant authorities
- Beer, Viable System Model; Project Cybersyn, Chile 1971-73
- NASA ASRS (1976-): confidential, non-punitive reporting; aviation
  safety; "just culture"
- FAO 2021: lower deforestation on Indigenous-managed land, Latin America
- Akerlof 1970: information asymmetry drives good goods out
- industrial farming: owner decoupled from land; diminishing return per
  energy input ([stated] by Kavik)
- this repo: forest holdout (PRs #330-#334) - pooled measure across
  unrecorded lab protocols hid the denominator
