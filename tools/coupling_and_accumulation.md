# Coupling and accumulation

CC0. Reusable reasoning moves. Nothing here describes a person.

The synthesis the specimens in `tools/bin_self_test.md` point to. Each
section states a move and ends with a check a reader can run.

## 1. The root prior: accumulation

Under the bins sits one prior: agents accumulate. A reading built on it
scores every absence of hoarding as an error:

    did not spend / did not hold        -> "cheap"
    did not stockpile credentials       -> "uncredentialed"
    did not stockpile sample count      -> "anecdotal"
    did not specialize (hold one domain) -> "master of none"

The bins differ in surface; the deleted term is the same - the system
the agent is coupled to.

Check: before scoring an absence as a deficit, ask whether the system
under reading accumulates at all, or cycles.

## 2. Coupled systems do not hoard

A tree returns oxygen. Its respiration depends on an atmosphere that
other organisms keep supplied, and its output is part of what keeps the
cycle running. Holding the output would starve the loop that produces
the input. In a coupled loop, release is the maintenance cost of the
coupling, not a loss.

Check: trace what the held quantity would otherwise feed. If it feeds
the supply of the holder's own input, holding it cuts the coupling.

## 3. Validation as calibration vs validation as stockpile

Calibration: a check against the system, spent when used, rerun as the
system drifts. It decays and is expected to decay.
Stockpile: checks accumulated and held as standing, read as permanent.

The same act of validation is one or the other depending on whether it
is rerun or banked. A stockpile is read as more validation; a recent
calibration may carry more information about the system now.

Check: when was the validation last run against the system it claims
to describe? A count of past validations does not answer this.

## 4. Monument vs foundation

A monument is built to be seen and bears no load, by definition; if it
carried load it would be structure. A foundation succeeds by being
unseen and holding. An accumulation frame optimizes for visibility, so
it optimizes for the monument - the one that cannot function. The
monument stands on the unseen foundation.

Check: for any visible achievement, name what it stands on and whether
that layer is counted anywhere.

## 5. Visibility measures and self-sealing erasure

A practice organized on the foundation frame scores near zero on any
visibility measure, because its success condition is not being seen.
The erasure seals itself: the measure that would register the loss is
the measure that cannot see the thing lost.

Author-neutral instruments are a translation layer. They carry the move
without carrying a visible author, so they pass into a
visibility-measured record without becoming a monument.

Check: does the measure in use have any way to register a working
foundation? If it can only register visible output, a zero is a
property of the measure.

## 6. CC0 as the foundation frame in license form

CC0 releases the work into the commons, accumulates no standing for the
releaser, and lets the work carry load unseen. It is the coupling move
written as a license.

## 7. The oxygen thought experiment

Suppose an oxygen producer treated its output as an asset and held it.
Its own respiration draws on the shared atmosphere; the stock it holds
is the stock missing from that atmosphere; the cycle that resupplies
it slows by the amount withheld. The hoarder is starved by its own
stockpile's absence from the loop. No figures are needed for the
direction; the sign follows from the loop.

Check: for a held quantity, write the loop. If the holder is
downstream of its own output, holding has a sign, and it is negative
for the holder.

## 8. Naivety inverted

Coupled cycling (oxygen, carbon, nitrogen) has run on geological time.
Accumulation as the organizing rule is recent by comparison and untested
at that horizon. Reading the commons as naive and accumulation as
sophisticated reads recency as superiority.

Check: over what horizon has each arrangement been run? Compare the
horizons before comparing the arrangements.

## 9. The validity cut

A measurement needs a stable base: something that holds still long
enough, relative to the instrument, to be measured. A system with no
stable base has no measurable object. Continuous patching is the
signature of a thing that never reached a measurable state - each patch
moves the object the last measurement was taken on.

Check: did the thing being measured hold still for the duration of the
measurement, on the instrument's clock?

## 10. The money token

A money unit looks stable only relative to faster processes. It moves
on its own timescale; its stillness is relative, not absolute. Those
measured in it do not set its rate, so they are measured against a
moving target they have no say in.

Check: state the timescale on which the unit is being treated as fixed,
and what moves faster and slower than it.

## 11. The upside-down pyramid

The validity cut (section 9) fused with an energy ledger. A structure
whose holding-up energy exceeds the value it was built to produce has
negative net output. It stands only while something outside it pays the
difference, and measuring it requires the stable base it does not have.

Check: ledger the energy to keep it standing against the value it
returns, on the same unit and over the same interval. A negative net
with an external subsidy is the shape.
